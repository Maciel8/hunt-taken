# Hunt Taken — protótipo

MMORPG idle no navegador: o personagem caça sozinho num mapa visível; o que você disputa com os outros é o lugar.

Protótipo em Canvas puro, um arquivo (`index.html`), sem build. Save no `localStorage` do navegador.

- Rota de hunt desenhada pelo jogador (até 8 pontos)
- Três hunts, monstros com respawn, skills por uso, depósito, bênção, morte com perda
- Rivais de outros reinos que dividem spawn e tomam hunt ("hunt taken")
- Relatório de volta com progresso off-line (até 12 h)

Documento de design: ver o GDD no Claude (privado).

## Rodar

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático.
